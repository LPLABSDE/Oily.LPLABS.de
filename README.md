## 🔧 App-Details anpassen

Bearbeite in `index.html` das `appData` Objekt:

```javascript
const appData = {
  oily: {
    de: {
      title: 'Oily',
      subtitle: 'Wartungstagebuch für Android',
      description: 'Deine Beschreibung...',
      features: ['Feature 1', 'Feature 2', ...]
    }
  }
};
```
